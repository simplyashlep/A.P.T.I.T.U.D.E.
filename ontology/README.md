# Aptitude Legal Ontology

Ground truth structured legal knowledge for deterministic mapping of lived experiences to claims, doctrines, remedies, and procedural pathways.

See main Aptitude System Technical Manual (LaTeX) for full specification.

## Top Level Classes
- Event
- Claim
- Doctrine
- Statute
- Policy
- Remedy

## Current Module
Misidentification / False Arrest (Oregon focus initially)

Loaded by backend.agents.* and orchestration.
